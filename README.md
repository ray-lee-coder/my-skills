## Quick Start

```bash
git clone https://github.com/ray-lee-coder/my-skills.git
cd my-skills
cp -r */SKILL.md ~/.hermes/skills/
```

Then ask your AI assistant naturally — skills auto-trigger on keywords.

> *"I sell pet clothes on Shopify doing $8K/month. How do I get to $20K in 6 months?"*
> → triggers `biz/ecommerce-growth-strategy` automatically.

> *"We're launching a new AI writing assistant — map the riskiest assumptions."*
> → triggers `dev/identify-assumptions-new` + `dev/prioritize-assumptions` automatically.
