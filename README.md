# my-skills

## 目录

| 分类 | 数量 | 用途 |
|---|---|---|
| `dev/` | 19 | 代码/工程/测试/安全（中文）|
| `doc/` | 5 | 文档/写作/电子表格 |
| `marketing/` | 33 | 内容/品牌/CRO/SEO/视觉 |
| `biz/` | 12 | 电商 5 平台（Amazon/Shopify/TikTok/eBay/Walmart）|
| `meta/` | 10 | 元工具（管理 skill 本身）/测试/MCP/学术 |

## 安装

```bash
git clone https://github.com/ray-lee-coder/my-skills.git
cd my-skills
# 各 skill 目录里都有 SKILL.md
# 通过 Hermes / OpenClaw / Claude Code 加载
```

## 评分卡

每个 skill 按 4 维加权（安全性 25% / 有效性 30% / 稳定性 25% / 非重复 20%）入选。详见 `SKILL-SCORING.md`（待补充）。
